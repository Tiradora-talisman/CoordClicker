# CoordClicker v1.0.0

First public release.

## What it does
Save two spots in any Windows window, then loop clicks or scrolls on them with hotkeys. Clicks go straight to the target window, so you can keep using your computer.

## Download
Download **CoordClicker.exe** below. Nothing else needs to be installed. Windows only.

## Quick start
1. Hover over the first spot and press F1 (Right point).
2. Hover over the second spot and press F2 (Left point).
3. Pick an action for each point, set Amount and Delay.
4. Press F3 to start and F3 again to stop.

## Notes
* Some antivirus tools flag PyInstaller exes. This is a known false positive. The full source is in the repository and you can build the exe yourself.
* If hotkeys do not work while a game is focused, run the exe as administrator.
* Please follow the rules of any game or program you use this with.
